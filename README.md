# XIMB Xpressions 2026

A responsive, dependency-free festival site. The home page includes the countdown, artist highlights, date-filtered hourly calendar, registration forms, gallery, contact details, and login entry point. The full lineup is on `artists.html`.

## Run

Open `index.html` directly in a browser. The site uses plain HTML, CSS, and JavaScript, so no build step or package installation is needed.

## Content to replace

Artist names and event details are placeholders. Portraits use remote sample images and should be replaced with approved Xpressions artist photography. Registration and login currently show front-end confirmation only; connect them to event registration and account services before accepting submissions.

The official Xavier Institute of Management / XIM University logo is included at `assets/xim-logo.png` and used in the shared header and footer.

## Calendar

The calendar covers October 13, 2026 through January 20, 2027. Select a year, month, and date to see all 24 hourly slots. Three nightly artist sets appear between 6 PM and 9 PM on January 15, 16, and 17, 2027.
